# Diplomarbeit — Polizeisportverein App

Final-year diploma thesis (HTL St. Pölten, Informatik, Matura 2026).

## Project
A mobile membership platform for the Police Sports Association of Lower Austria (LPSV NÖ), built as project lead of a student team.

**Stack:** Flutter (frontend), Spring Boot (backend), Supabase, Firebase (push notifications)

**Features:** digital membership cards, push notifications, Stripe payments, admin role-based access control (RBAC)

## My role
Project lead. When two team members delivered roughly half the expected work, I cut the planned ID Austria (Austrian digital ID) integration from the practical implementation — replacing it with simple email/password auth — while keeping the full theoretical treatment of ID Austria in the written thesis, since that carried the academic weight. I reassigned tasks based on actual delivery capacity, not role. The project shipped and the thesis was awarded an excellent grade.
